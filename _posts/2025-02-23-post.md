# Jekyll

## basic components

1. Liquid syntax, which is kind of template language that manipulates
pages and variables.

2. `_layouts` folder it is the standard of html template
3. `_includes` folder contains reusable html components, improving code
readability by avoiding repetition.  
4. `assets` folder where to store `js`, `css` and `images`
5. `_sass` folder stord the actual css design
6. The `_data` folder uses `.yml` files to store simple data, such as arrays.
